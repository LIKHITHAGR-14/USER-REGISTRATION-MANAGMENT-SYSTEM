👤 User Registration Management System
📌 Overview
User Registration Management System is a Java-based application developed to collect, store, and manage user information. The application uses Java Swing to provide a simple Graphical User Interface (GUI) and MySQL to store and manage user details.

The system allows users to register by entering their personal information, including name, email, password, gender, and city. It also provides an option to upload a photograph from the local computer using a file browsing feature. After registration, users can view their entered details and make changes if required.

This project demonstrates the use of Java programming, database connectivity, and SQL operations for developing a user registration application.
✨ Features
- 📝 Register new users.
- 👤 Enter personal details such as name and email.
- 🔐 Store user password information.
- 🚻 Select gender and city.
- 📷 Upload user photographs from the local computer.
- 📊 Display registered user details.
- ✏️ Edit and update user information.
- 🗄️ Store and manage user details using MySQL.
- 🔗 Database connectivity using JDBC.
- 💻 Simple and user-friendly GUI.

⚙️ Installation
1. Clone the Repository
git clone https://github.com/your-username/User-Registration-Management-System.git
cd User-Registration-Management-System


2. Install Required Software
- Install Java JDK.
- Install MySQL Server.
- Install Eclipse or NetBeans IDE.
- Add MySQL JDBC Connector to the project.
3. Configure Database
- Open MySQL.
- Create a database for user registration.
- Create the required user details table.
- Configure the JDBC connection with your MySQL username and password.
4. Run the Application

Open the project in your Java IDE and execute the main Java file.
▶️ How It Works
1. Open the User Registration Management System application.
2. The registration form is displayed.
3. Enter personal details such as name, email, and password.
4. Select gender and city.
5. Upload a photograph using the Browse option.
6. Submit the registration form.
7. The entered information is stored in the MySQL database using JDBC.
8. The registered user details are displayed on the next screen.
9. Users can edit their details if required.
